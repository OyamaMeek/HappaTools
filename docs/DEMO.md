# Finder 演示验收与录制步骤

必须使用已启用且可访问共享容器的签名应用录制；不以模拟画面代替实际 Finder 操作。

1. 在专用演示目录创建 Git 仓库和本地 bare 远端，设置作者身份与当前分支 upstream。
2. 在“系统设置 → 通用 → 登录项与扩展 → 扩展 → 文件提供程序”启用 `HappaTools` 和 `HappaTools README`，再打开 HappaTools 概览，展示两个扩展状态及权限指引。
3. 打开 Finder 演示仓库，点击 README 菜单，展示新建空文件；再次执行，展示不覆盖提示。
4. 修改一个受版本管理文件，点击 Git → 提交并推送，展示默认时间戳和多行编辑。
5. 提交时重新打开菜单，展示忙碌状态；完成后在主应用历史和日志展示两条成功记录。
6. 在同一分支无新更改时重试，展示仍可推送；将远端设为不可用，展示失败日志与保留的本地提交。
7. 在普通非 Git 文件夹操作 Git，展示“当前目录不是 Git 仓库”；在缺 upstream 仓库操作，确认没有暂存/提交副作用。
8. 展示设置保存、日志搜索及清空确认，并重启应用核实持久化。

Finder 按钮需要通过“显示 → 自定工具栏”加入。README 扩展位于独立 helper app，以便系统设置显示独立开关；同时检查两个 Finder 窗口、挂载外部卷、第三方云盘扩展并存以及 `targetedURL()` 为空后的文件夹选择。

当前提供的是可复现录制脚本，尚未产出演示视频；实际 Finder 授权与分发签名验收完成后再录制。
